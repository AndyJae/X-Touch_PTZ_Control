# Behringer_PTZ

Development environment scaffold for the PTZ Shading Tool specification.

## Stack

- Python 3.11+
- mido + python-rtmidi
- httpx
- FastAPI + HTMX + WebSocket
- pydantic + YAML

## Quick start

1. Create and activate a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python main.py`

## Notes

This repository currently contains the specification and a minimal development scaffold. Implementation work should stay aligned to [ptz-shading-tool-spec.md](ptz-shading-tool-spec.md).
