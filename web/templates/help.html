Overview

X-Touch PTZ Control connects a Behringer X-Touch Extender to Panasonic PTZ cameras for live iris/shading control, plus gain, pedestal and ND filter adjustment — from the web UI or the physical surface. Which features are available depends on the connected camera model.

We recommend using the latest version of Google Chrome — that's what this project is developed and tested with.

Getting Started

  1. Set the X-Touch Extender to MC (Mackie Control) mode (hold Select 1 while powering it on — see the X-Touch Extender manual). Other controller modes are not supported by this software.
  2. Connect the X-Touch Extender via USB before starting the software — it is only detected at startup, not while the app is already running.
  3. Start X-Touch PTZ Control — the web UI opens automatically in your browser, and an icon appears in the system tray. See "System tray" below.
  4. Open Setup and register a camera per channel: name, IP, port, then click Connect Camera.
  5. The X-Touch Extender is detected automatically at startup. Without a connected surface, the web UI keeps working on its own.
  6. Optionally set a Bitfocus Companion host/port on the Setup page to enable the SELECT button.

System tray

X-Touch PTZ Control keeps running in the system tray for as long as it's open — closing the browser tab/window does not stop it.

  • Click the tray icon (or right-click it and choose Open) to reopen the web UI.
  • Right-click the tray icon and choose Quit to actually shut the app down.

Control page

Each of the 8 channels has a fader, an encoder, two assignable buttons (Solo/Mute), and a SELECT button.

  • Fader — drag to move the iris live. The physical motor fader also follows iris changes made elsewhere (e.g. the camera's own web UI).
  • REC button — cycles the encoder's function: Gain → Pedestal → ND → Camera Info.
  • Encoder — turning it adjusts the active function live.
  • Solo / Mute buttons — click the gear icon (⚙) to assign a camera feature (e.g. Auto Focus, Knee, DRS — depends on the model), then click the button to toggle it.
  • SELECT — triggers a Bitfocus Companion button, if a Page/Row/Column target is assigned for that channel on the Setup page.

Setup page

  • Companion Config — host/port for the optional Companion integration.
  • Camera & Button Assignment — one row per channel: connect/disconnect a camera, rename it, assign Solo/Mute button features, assign a Companion target. Disconnecting a camera also removes it from config.yaml.

Logs page

Shows the last 200 log entries, filterable by level (ALL/DEBUG/INFO/WARNING/ERROR).
